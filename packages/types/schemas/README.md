# sing-box configuration schema

The only supported export target is **sing-box 1.14.0**.

`sing-box.json` is generated by the official 1.14.0 release binary:

```sh
sing-box schema -o packages/types/schemas/sing-box.json
```

Release: https://github.com/SagerNet/sing-box/releases/tag/v1.14.0

After replacing the schema, run `pnpm --filter @uni-conf/types generate:protocols`
to regenerate native outbound types and protocol field metadata. Export validation
uses this same checked-in schema so it does not depend on network access or a
changing documentation schema. Generated configs declare the official editor
schema URL and use explicit HTTP clients for remote rule-set downloads.
