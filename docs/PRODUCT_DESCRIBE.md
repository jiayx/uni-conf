# UniConf 使用指南

## 基本流程

1. 创建或选择一个配置空间。
2. 添加订阅、导入配置或手动录入节点。
3. 检查节点信息和启用状态。
4. 配置节点组和分流方案。
5. 按需添加手动规则或补充规则集。
6. 预览目标客户端配置。
7. 下载配置，或将订阅链接添加到客户端。

## 配置空间

配置空间用于隔离不同的节点、分流和导出配置。

同一套节点只需要导出给不同客户端时，使用同一个配置空间并创建多个导出档案即可。只有订阅、节点、分流或 DNS 需要分别维护时，才需要创建新的配置空间。

配置空间不是账号。所有配置空间都由同一个管理端访问密钥管理。

## 订阅与导入

### 添加订阅

添加订阅链接时，只需要填写 URL。名称留空时，UniConf 会尝试从 URL 和其中的 `name` 参数识别名称。

可以按订阅单独设置：

- 配置格式
- User-Agent
- 刷新间隔
- 是否启用

默认自动刷新间隔为 240 分钟。设置为 `0` 时使用全局刷新间隔。

停用订阅后，其中的节点不会参与节点组和配置导出。

### 导入已有配置

支持粘贴或上传：

- Clash/Mihomo YAML
- sing-box JSON
- Base64 节点订阅
- 节点 URI 文本
- Clash/Mihomo 规则配置

导入前可以预览新增、重复、冲突和无法识别的内容。导入完成后可以撤销。

## 节点

支持以下协议：

`ss`、`ssr`、`vmess`、`vless`、`trojan`、`hysteria`、`hysteria2`、`tuic`、`anytls`、`naive`、`wireguard`、`socks5`、`http`、`https`、`ssh`、`shadowtls`。

选择导出格式后，预览页面会显示可用节点和兼容性提示。

节点页面支持：

- 按名称、服务器、来源和地区搜索
- 按协议、地区、来源和启用状态筛选
- 批量启用或停用
- 手动修改国家或地区
- 根据节点名称自动识别国家或地区
- 标记高倍率等自定义标签

订阅中仅用于展示套餐、流量或到期时间的无效节点，可以通过名称过滤或标签排除。

## 节点组

节点组可以从以下条件选择节点：

- 订阅来源
- 指定节点
- 名称或服务器
- 协议
- 国家或地区
- 标签

还可以设置节点名称处理、排序和去重规则。

系统默认提供：

- 默认节点池
- 全部节点
- 节点选择
- 自动选择
- 故障切换
- 已启用的国家、地区和标签节点组

默认节点池会排除标记为高倍率的节点。自动节点组可以选择 `url-test`、`select` 或 `fallback` 类型。

## 分流方案

### 基础分流方式

可以选择：

- 默认代理：私网和明确的直连流量走 DIRECT，其他未匹配流量走 PROXY。
- 默认直连：明确需要代理的流量走 PROXY，其他未匹配流量走 DIRECT。

切换基础分流方式会同时调整相关基础规则和兜底出口。

### 业务分流场景

可以启用以下场景：

| 场景       | 包含的业务组                             |
| ---------- | ---------------------------------------- |
| AI 与开发  | AI、GitHub、Google、Microsoft、Developer |
| 流媒体     | Streaming                                |
| 通讯与社交 | Social                                   |
| 游戏       | Gaming                                   |
| 加密货币   | Crypto                                   |
| 券商       | Broker                                   |
| 网络诊断   | Speedtest                                |
| 平台服务   | Apple、Microsoft、Google                 |

每个业务组可以直接选择默认出口。Speedtest 默认使用 DIRECT，也可以改为某个节点或节点组。

还可以创建自定义策略组，用于承接手动规则或规则集。

## 规则

### 手动规则

支持域名、域名后缀、关键词、正则、IP CIDR、ASN、GeoIP、GeoSite、进程、端口、来源 IP、协议、网络、入站类型、规则集、脚本和 MATCH 等规则。

规则从上到下匹配。更具体的规则应放在更靠前的位置。

IP 规则可以选择 `no-resolve`，导出时会根据客户端和规则类型自动处理。

### 远程规则集

规则集管理页面会列出当前配置使用的系统规则和补充规则。

系统规则可以：

- 启用或停用
- 修改目标出口
- 为特定客户端添加原生规则集地址

添加补充规则集时，可以从 QuixoticHeart 目录选择，也可以直接填写规则集 URL。导入配置时，订阅中声明的规则集也可以一并导入。

如果某条规则已经归入一个业务组，但希望单独指定出口，可以为该规则集设置目标覆盖。

### 规则集转换

规则集支持文本、YAML、JSON、Mihomo MRS 和 sing-box SRS。

转换方式：

- 兼容模式：保留能够准确转换的规则，并提示被省略的内容。
- 严格模式：只要存在无法准确转换的规则，就阻止下载和订阅更新。

需要保留客户端专属指令时，可以设置该客户端的原生规则集地址。

## DNS

DNS 设置包括：

- 地址响应方式
- DNS 解析路由
- 真实 IP 例外域名
- 是否包含系统维护的真实 IP 例外

完整配置会根据目标客户端支持的 DNS 结构生成。纯节点订阅不包含 DNS 设置。

使用 Fake IP 时，系统维护的真实 IP 例外可以减少局域网、连接检测和部分服务的兼容问题。也可以在设置中添加自己的真实 IP 域名。

Mihomo 导出会包含 GeoIP、GeoSite、Country MMDB 和 ASN 数据地址。

## 配置导出

### 默认导出

默认导出包含当前配置空间中的全部可用内容，可以选择目标客户端格式并生成订阅链接。

### 高级导出档案

高级档案可以单独选择：

- 固定的导出格式
- 节点组
- 策略组和出口
- 手动规则
- 远程规则集
- 规则集转换方式

适合为不同设备或朋友生成范围不同的配置。

### 暂停和重置 Token

- 暂停：已有订阅链接停止提供配置。
- 恢复：原订阅链接继续使用。
- 重置 Token：旧链接立即失效，需要把新链接重新添加到客户端。

### 支持的格式

- Mihomo
- Clash
- sing-box
- Loon
- Surge
- Shadowrocket
- Quantumult X
- Stash
- Egern
- Base64 节点订阅
- 明文节点订阅

预览页面会显示兼容性提示、规则集转换结果和阻止导出的错误。没有阻断问题时即可下载或复制订阅链接。

## 设置

设置页面可以管理：

- 语言和主题
- 默认代理或默认直连
- 业务分流场景
- 业务组出口
- 节点命名
- DNS
- 兼容性提示
- 规则集转换方式
- 订阅自动刷新
- 自动节点组

## 备份与恢复

数据管理页面支持：

- 导出备份
- 校验并恢复备份
- 清空当前配置

备份包含订阅地址、节点凭据和导出 Token，应当作为秘密文件保存。
